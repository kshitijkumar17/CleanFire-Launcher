# CleanFire Launcher 1.0.0

Prepared 2026-10-24 · application ID `dev.karat.materialhome` · versionCode 184

CleanFire Launcher is a Material-inspired Fire TV Home screen based on [Material TV Launcher by 0xRampey](https://github.com/0xRampey/material-tv-launcher). It offers six editable Home apps, an alphabetical Apps grid with visibility controls, native Settings shortcuts, D-pad navigation, and keyless local weather with offline cache.

The tested device is a Fire TV Stick 4K, 2nd generation (AFTKM), on Fire OS 8.1.8.5 / Android 11. Other devices and firmware are unverified. Amazon's stock launcher remains installed; Home on Fire is optional and configured separately. Fire OS's app library may show the square icon rather than the packaged 16:9 TV banner.

Install a published APK with `adb connect FIRE_TV_IP:5555`, then `adb install CleanFire-Launcher-v1.0.0.apk`. Open it with `adb shell am start -n dev.karat.materialhome/com.rampey.materialtv.HomeActivity`. See the repository README for setup and remote controls.

**Signing migration:** this APK uses a new persistent release certificate. Existing debug-signed `dev.karat.materialhome` installations cannot update to it in place. Android will reject an update with a different certificate; removing the old installation can erase saved launcher preferences and may require checking Home on Fire's target again. This release APK was statically signed and verified, but could not be installed over the debug-signed test device without removing that working installation. Do not uninstall it merely to test the public build.

Weather uses ipdata.free and Open-Meteo over HTTPS. City detection is approximate and can be wrong under a VPN or shared ISP gateway. The keyless Open-Meteo service is limited to non-commercial use and can rate-limit or fail; cached readings remain available offline. No API key is required.
