# Changelog

## 1.0.0 — 2026-10-24

- First prepared public release of CleanFire Launcher for Fire OS 8 (versionCode 184).
- Added the CleanFire name and artwork while retaining application ID `dev.karat.materialhome`.
- Retained the original Material-inspired Java UI with six customizable Home slots, app discovery and visibility controls, native Fire TV Settings shortcuts, and D-pad navigation.
- Added keyless IP-based location and Open-Meteo weather, offline cache, and visible provider attribution.
- Added separate debug/release build modes and a CI debug build. Release signing uses a persistent key outside Git.
- Replaced upstream setup text and screenshots with Fire OS-specific documentation and a real AFTKM Home capture.

Historical porting steps and device results remain in [DEVELOPMENT_LOG.md](DEVELOPMENT_LOG.md).
